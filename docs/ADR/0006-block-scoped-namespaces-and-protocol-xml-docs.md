# 0006. Block-scoped namespaces; protocol contracts carry XML docs

- **Status:** Accepted
- **Date:** Not recorded - from the round-2 fact sheet, before 2026-09-08
- **Formerly:** `docs/decisions.md` section 7b, standing decision 6

## Context

From the round-2 fact sheet, decided by the maintainer with reasons.

## Decision

**Block-scoped namespaces are required**; public protocol contracts carry XML docs on properties.

## Consequences

The convention and its example are in `CLAUDE.md` under *Conventions for the rewrite*. A hook or reviewer asking for file-scoped namespaces carries another project's rules.
